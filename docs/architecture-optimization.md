## 前端改造依据

- **业务数据可信：** 总览、监测、策略、诊断、自进化、内容、事实和实验页面取消硬编码业务样本、收益与执行进度。明确区分空数据、未知指标和读取错误。策略识别后端 backlog / production / review / analyzing，诊断评分采用 0–100。官网预约入口改为实际项目监测导航，不再假称提交成功。
- **权限一致：** 使用服务端有效项目权限，变更、审核和配置控件分别要求 write / review / admin。读取失败后立即禁用变更；副驾驶指令、历史修改、技能配置和审批同步受限。
- **状态与模块边界：** 资源按会话代数、用户、项目隔离，合并并发请求，使用弱引用避免分页 loader 缓存持续积累。切换项目或会话后，迟到响应不能覆盖新状态。工作台与抽屉共享对话控制器，会话列表和 Harness 面板拆为独立组件。
- **安全渲染与协议：** 使用局部 Marked 实例及 DOMPurify，清洗脚本、事件属性、危险链接和代码语言注入。复制使用 Clipboard API 与文本。SSE 支持 CRLF、多行 data、有限缓冲和异常结束检测。
- **交互与性能：** TypeScript strict、页面错误边界、焦点可见、减少动画偏好、弹窗焦点约束及恢复、移动端会话切换。抽屉和资料弹窗按需加载，删除模拟打字延迟。隐藏页面暂停轮询。头像上传与服务端 PNG/JPEG、2MB 限制一致，错误不再静默回退为本地成功。
- **分页与审核：** 公共列表每页最多 100 项，筛选与数量表示本页范围。编辑内容后失效旧核验结果及审批资格，成功反馈由实际请求和持久任务状态决定。

## 后端改造依据

- **组合与授权明确：** 大路由文件拆成认证、业务、副驾驶、Harness 和系统模块；HTTP / Worker 共用 Runtime。用例依赖领域 EventSink，解除对 WebSocket delivery 的反向依赖。受保护路由按方法和完整路径声明权限，未配置策略的路由拒绝访问，测试检查已注册项目路由完整性。
- **会话可撤销且保持私有：** 持久 auth_version 纳入 JWT 校验；改密和退出撤销旧 access / refresh。改密采用密码哈希条件更新。WebSocket 发送及心跳重查账号、版本、项目成员和过期时间，不保留 Gin context。个人会话所有权同时覆盖运行轨迹和工具输入日志，防止旁路读取。
- **迁移与就绪可核查：** schema v1–v3 按序、事务执行，PostgreSQL 使用迁移锁。新增字段、对账索引和任务 / 成员 / 会话消息关系约束。迁移可重复执行并保留密码；SQLite 外键重建表时恢复原有普通、唯一和自定义索引，回归实际模拟无外键的 v1。就绪验证版本、表、字段、任务索引、约束，使用 3 秒期限。
- **任务恢复有进度：** 按最旧未对账 failed / cancelled 记录读取，每轮最多 200 条；对账标记与父任务 / 卡片更新保持事务一致。205 个失败批次的回归验证多轮处理不会饿死旧任务，审批卡片按 interrupt ID 匹配。
- **证据覆盖完整内容：** 标题、Markdown 标题和正文都进入已批准事实的逐句匹配；编辑后重新核验与审批。保守匹配不能代替来源真实性或语义审查。
- **请求与运行可控：** HTTP 集合限制 1–100 项，错误参数返回 400；Worker 的完整证据查询不受公共分页影响。共享外部 HTTP Transport 保留公网 DNS / 重定向保护。新增安全响应头和 CSP。管理员状态接口读取真实任务计数、过期租约与未知发布回执。
- **配置与依赖真实：** 拒绝未实现的自动摘要 / 默认模型字段，完全遮蔽模型凭证。升级 Go 到 1.26.6、quic-go 到 0.59.1，消除上一轮扫描发现的可达漏洞。

## 升级与回退

本次没有提交代码、部署服务、对外发布业务内容或迁移真实业务数据库。

已有安装需要备份后显式运行 `go run ./cmd/manage migrate`。HTTP / Worker 只验证 schema，未迁移到 v3 时会拒绝就绪。v3 遇到孤立任务、成员或消息时事务回滚，不会自动删数据，应先核查业务来源并修复完整性。没有自动向下迁移，代码回退需匹配 schema 或恢复备份。

改密 / 退出使既有会话失效，其他已登录窗口需要重新登录。原有短密码账号可以继续登录，新密码要求 12–72 字节。公共集合默认最多 100 项，客户端需要遵循 pagination 的 limit / offset / has_more；旧的无界列表客户端需要同步适配。
